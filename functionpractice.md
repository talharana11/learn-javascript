# Practice Code

Har question ka pehle khud solution likho, phir neeche solution se check karo.

## Level 1: Basic

**Q1.** Ek function likho jo do numbers ka sum return kare.

**Q2.** Ek function `isEven(n)` likho jo `true` ya `false` return kare.

**Q3.** Arrow function mein `square(n)` likho.

**Q4.** `greet(name)` function likho jis mein name na dene par "Guest" aaye.

**Q5.** Ek function likho jo string ko reverse kare.

## Level 2: Intermediate

**Q6.** `sum(...nums)` likho jo kitne bhi numbers ka sum de.

**Q7.** Array `[1,2,3,4,5,6]` se sirf even numbers `filter` karo aur unka `map` se square nikalo.

**Q8.** `counter()` closure likho jis mein `increment`, `decrement`, `getValue` methods hon.

**Q9.** `multiplier(factor)` function factory likho.

**Q10.** `findMax(arr)` likho bina `Math.max` ke.

## Level 3: Advanced

**Q11.** `factorial(n)` recursion se likho.

**Q12.** `fibonacci(n)` recursion se likho.

**Q13.** `compose(f, g)` likho jo `f(g(x))` return kare.

**Q14.** `once(fn)` likho: function sirf pehli baar chale, baad mein pehla result hi return kare.

**Q15.** `debounce(fn, delay)` likho (search input mein use hota hai).

---

## Bonus Challenges

1. Ek `calculator` object banao jis ke methods `add`, `subtract`, `multiply`, `divide` hon (divide by zero handle karo).
2. `pipe(...fns)` function likho jo kitne bhi functions ko left-to-right chalaye.
3. `memoize(fn)` likho jo pehle se calculate hui values cache kare.
4. Ek `async` function likho jo API se data fetch kare aur `try/catch` se error handle kare.
